\#Ticket 1: Can't install driver. It's showing print spooler is disabled



To enable printer services

\-> Search services. MSc -> Run as administrator -> find Print Spooler -> if it is disable -> Choose status type is Automatic -> complete





\#Ticket 2: Laptop charge not exceeding more than 25% not matter if we plug charger for whole day



Other optional check: -> Task manager: If there are many services consume too much memory or cpu

\--> Mainly is hardware problem:

1. Problem is the charger is too weak ( maybe some warning on laptop like: "Low-power charger detected")
2. Battery cell die ( Maybe 75% of them is dead, so only one can charge )
