Most of these tickets are questions from network and security certification.



#Ticket 1: A customer opened a file attachment, and now her PC is infected with ransomware, She's unable to open any of her files.

Protect your PC: Window Defender -> Virus & threat protection -> Turn on Ransomware protection.

Priority turning off your computer -> Ask help from a professor in this major.



#Ticket 2: Your manager ask you to set up a secure network connection at remote site to move over some backups, which protocol would you use ? ( FTP, DHCP, IP, SFTP )

FTP -> is not a secure file transfer protocol
DHCP -> assign IP dynamically ( it could be home router or modem )
IP -> Internet protocol
SFTP -> correct



#Ticket 3: A user is unable to reach google.com by typing URL in web browser but it is able to reach it by typing 172.217.3.110.

Solution: Run as administrator CMD -> run `ipconfig /flushdns`: clear your computer's stored network addresses.
