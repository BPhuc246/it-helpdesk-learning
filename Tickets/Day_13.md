#Ticket 1: A user login to computer have the internet but outlook is not updating, pop enter password, if password entered it is not excepting. Incorrect password. Password reseted from O365 admin center but still it is not working. What is the troubleshooting step ? 

-> Check to see if user typing password correctly, and you give user the correct password
-> Make sure user is not logged in somewhere with old password.
-> Check if they are in VPN, make sure they are connected the company network
-> Try any version of outlook ( Desktop or Web )



#Ticket 2: Laptop won't connect to display screen or TV through HDMI

-> Go to Display Settings -> Select advance display setting in "Multiple  Display" -> Your display device that plugged will show ( if not check the cable )



#Ticket 3: Can't connect to sonicwall netextender, customer's printer is not printing on computer but it works for other coworkers.

-> Make sure your printer is installed correctly
-> Make sure printer is added correctly in "Printers & Scanners".



#Ticket 4: Acer laptop, backspace and enter button is not working, customer tried going to device manager uninstall and reinstall the keyboard drivers, but it stay the same.

-> Check if laptop's keyboard is dirty and needs to be cleaned or replace.



#Ticket 5: How to configure a DNS server

-> Hover to Wifi and click "Network and Internet settings" -> Select Wifi, click properties of that Wifi -> Scroll down and you will see the configuration.
