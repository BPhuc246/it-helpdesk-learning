#Ticket 1: How to delete or remove the software installed from the registry

*Warning: Be careful not to delete anything that your OS might be using*

-> Search "Registry Editor" then run as administrator -> Find and expand the folder SOFTWARE in HKEY_LOCAL_MACHINE -> Then you can see software's name that you want to delete -> Right click it, and delete.

#Ticket 4: Customer can't log in to his office desktop remotely

Troubleshooting:
Ping to your laptop (by domain name or IP) to make sure is it offline or online
Open System Properties -> Make sure you checked "Allow Remote Assistance" in Remote tab 
Change hostname to its IP ( v4 or v6 is fine )
