#Ticket 2: How to enter into safe mode in window 10, to enable uninstalling unstable programs.

Long way: Settings -> Upgrade & Security -> Recovery -> Restart now -> ( Press F12 or any key that your computer can open boot ) -> Troubleshooting -> Advanced options -> Startup settings ( read all options ) -> Restart -> Now safe mode is allow ( F4 )

Short way: Settings -> Apps & Features -> Uninstall any programs you want

What is difference ?
Short Way (Normal Mode): The program is actively running in the background. If it is unstable or broken, it can crash your system or lock its own files, giving you errors like "File in use" when you try to uninstall it.

Long Way (Safe Mode): Windows loads only basic files, blocking all third-party programs from running. Because the unstable program is completely frozen in the background, you can safely remove it without errors or crashes.

TL;DR: Use the Short Way for normal apps (Spotify, games). Use the Long Way (Safe Mode) when an app is crashing your PC or refuses to uninstall.
