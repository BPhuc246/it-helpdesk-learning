Go to services. MSc - Find Printer Spooler -> Stop, restart, or restart ( clear the queue in printer )

#Ticket 3: Can't use webcam in meetings

Ask customer to take control computer to install 

Possible problems:
+ Driver webcam is repairing
+ Webcam is disable in setting
+ Broken webcam
+ Camera did not install yet

Some solutions:
+ In meetings -> try click open camera to check if there are any errors pop up ( like: select another video camera in settings )
+ Check "Imaging devices" in Device Manager ( search in window ) -> If it has ! -> just click to install
+ Or just uninstall it and install a new one ( Be careful )

If you have a tool to check where user logged last time -> use it
