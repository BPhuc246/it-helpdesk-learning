#Ticket 1: Outlook Freezing Issue: When customer searching for people on outlook, it freeze, so customer turned off hardware acceleration and turned off cached mode, repaired outlook, repaired office, uninstall and reinstall office 365, but no change

Possible problem: Turned off cached mode -> Stop the outlook from caching data for access faster data ( indexing )
Open Indexing options -> Modify -> Make sure your folder contain office has been checked ( checked = index -> Faster searching )
