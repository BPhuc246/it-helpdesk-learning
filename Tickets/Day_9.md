#Ticket 1: Lost file excel, customer can't find it

Solutions:
+ Ask for the file name and its last known location.
+ Check the Recycle Bin.
+ If the file is found, right-click it and select Restore.
+ If not found, search the computer, check Recent Files in Excel, or verify if it was saved to OneDrive



#Ticket 2: Emails blocked due to size

Solutions:
+ Compress the attachment using WinRAR, 7-Zip, or Windows ZIP.
+ If the file is still too large, upload it to OneDrive and generate a sharing link.



#Ticket 3: Unable to edit a Pnet profile, Error: "Invalid method specified"
Website: https://sanbs.ci.hr/...

Solutions:
+ Verify the error by reproducing the issue.
+ Take a screenshot of the error message.
+ Record the affected user account and the time the issue occurred.
+ Since this is a website/application issue, Helpdesk Level 1 cannot resolve it.



#Ticket 4: Unable to log in remotely ion a laptop. Error: "User account not authorized for remote login"

Solutions:
+ Open Computer Management.
+ Navigate to Local Users and Groups → Groups.
+ Check whether the user is a member of:
	+ Remote Desktop Users
	+ Administrators 
+ If not, add the user to the appropriate group.
+ Verify that Remote Desktop is enabled.
+Check that the Windows Firewall allows Remote Desktop (TCP Port 3389).
+ If the computer is joined to a domain, verify permissions in Active Directory or Group Policy
